# WORLD DIGITAL LIBRARY

A global digital book discovery platform.

## Files
- index.html: Website structure
- style.css: Website design
- script.js: Search engine and interactions

## Book Sources
- Open Library
- Google Books
- Project Gutenberg
- Internet Archive

## How to Run
Open index.html in your browser.

## GitHub Pages
1. Upload all files to your repository.
2. Open Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select main and /(root).
6. Click Save.

## Important
This project searches external book catalogs.
It does not host every book in the world.
Book access depends on the original provider's
availability, copyright, and access permissions.
